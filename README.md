# Tra cứu tiền nước – Trạm Nước sạch và VSMT Khu vực II

Trang web tra cứu chỉ số, tiền nước; báo hỏng, yêu cầu kiểm tra nước, báo vi phạm.

- Trang web: https://nuocsachkv2.github.io/
- Dữ liệu nằm ở Google Sheet của trạm; trang này chỉ là giao diện, gọi máy chủ Google Apps Script để lấy số liệu.
- Sửa giao diện: thay file `index.html` bằng bản `Index.html` mới (cùng nội dung với file trong Apps Script).
